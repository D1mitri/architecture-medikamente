# Необходимость защиты:

Для категории К1 - ФЗ-152 ст. 10
Для категории К2 - ФЗ-152 ст. 3
Для категории К3 - 98-ФЗ о коммерческой тайне
Для категории К4 - внутренние политики компании

# Инструменты защиты:

1. Обязательное шифрование (как при хранении, так и при передаче):
- Для данных в покое можно использовать VeraCrypt.
- Для шифрования при передаче Let's Encrypt.

2. Многофакторная аутентификация для доступа:
- Keycloak + Google Authenticator

3. Полное журналирование всех операций:
- Microsoft Purview

4. Регулярные аудиты доступа:
- ManageEngine ADAudit Plus

5. Маркировки на основе правил профилирования и классификации данных:
- Informatica Data Catalog для автоматической маркировки
